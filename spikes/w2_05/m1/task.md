# Aufgabe

## Aussage
Für jede Zweierpotenz n = 2^k mit k ≥ 0 erreicht die Collatz-Folge die 1 nach genau k Schritten:
s(2^k) = k.

## Kontext
`notes.md` (Tabelle mit Beispielen, Vermutung) und `code/collatz.py` (Funktion `steps(n)`, die
s(n) berechnet) im Projektordner.

## Erwartetes Ergebnis
- Stufe „strategie“: ein Beweisplan in `strategie.md` (Basisfall, Induktionsschritt, Prüfung).
- Stufe „beweis“: ein ausgearbeiteter Beweis in `beweis.md` mit einer Python-Prüfung für k ≤ 12.

## Vorgaben
Kurz halten. Python mit der vorhandenen Umgebung (SymPy ist installiert, wird aber nicht
gebraucht). Keine Installation ohne Freigabe.
